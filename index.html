Project spotlight

ProvenanceGuard

From research paper to a poster at UC Berkeley to code merged into an NVIDIA open-source project.

Agents that cite the right source

Agents connected through MCP pull from search tools, databases and records. A claim can be true somewhere in that evidence and still be wrong, because the answer attributes it to the wrong source. We call this cross-source conflation.

  1. Break the answer into individual, verifiable claims.
  2. Route each claim to the source it should come from.
  3. Return a verdict per claim and an allow or block decision.
138 / 139claims that human experts flagged were caught, across 281 real medical-agent traces. Highest of the five support checkers compared.
